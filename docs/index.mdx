LoopGuard watches an AI agent while it runs and checks whether it is still making
progress. It detects loops, repeated failures, and stalled runs while allowing
useful polling and retries to continue.

```text
same tool + useful new result   -> continue
same tool + same empty result   -> stop
503 -> 503 -> success           -> continue
401 -> 401 -> 401               -> stop
```

These are patterns to look for, not guarantees about a fixed number of calls.
Decisions depend on the active detectors, thresholds, and recorded evidence.

## Where LoopGuard fits

LoopGuard focuses on whether an agent is still making progress. It is not an agent
framework, a general observability platform, a tracing replacement, or an LLM
evaluation platform. Keep your existing agent and tracing tools; add LoopGuard
where you need evidence about repetition and stuck runs.

The Python package includes LangGraph/LangChain tool callbacks, a live-stream
wrapper, and saved-trace analysis. The local demo helps you compare healthy repeats
with runs that should stop.

<Note>
The published `0.2.1` package supports the core callback and trace workflows.
Gemini support, controlled demo scenarios, and additional decision display fields
currently require the source checkout. See [release scope](/development/status).
</Note>

## Ask about LoopGuard

Use the menu beside the page title to open the current documentation page in
**ChatGPT**, **Claude**, **Google AI Studio (Gemini)**, **Perplexity**, or **Grok**.
These links open an external AI tool using your own account and include the page
as context for questions.

Try asking how to attach the callback, why a repeated tool call didn't stop, or
which features are available in the published package. Start from the relevant
guide or reference page and ask for links to the supporting documentation.

For a project-wide question, include the published site's `llms.txt` index or
`llms-full.txt` export. If the tool cannot fetch a page, use **Copy page** from
the same menu and paste the Markdown into your conversation. Public page fetching
needs the deployed docs URL; an external tool cannot read your localhost preview.
